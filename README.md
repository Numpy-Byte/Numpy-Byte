* 🔭 **I’m currently working on:** [CodeFrame](https://github.com/Numpy-Byte/CodeFrame), a sleek desktop application for generating beautiful, modular code snapshots.
* 👯 **I’m looking to collaborate on:** Open-source developer tools, productivity apps, and unique GUI interfaces in Java/Python.
* 🤝 **I’m looking for help with:** Advanced Algorithm design and optimization techniques.
* 🌱 **I’m currently learning:** Mastering JavaFX, deepening my Object-Oriented Design patterns, and Data Structures.
* 💬 **Ask me about:** Java, Python, 3D modeling, high-fidelity photo editing, and software architecture.
